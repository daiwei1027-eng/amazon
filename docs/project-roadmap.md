## 固定评估协议

1. 固定当前 100 个共同商品、2 家门店、采样种子和日期边界。模型比较使用同一目标集合，验证与测试各一次预测未来 30 天。
2. 使用验证集选择超参数、特征和最佳 epoch。方案固定后才做测试集比较，测试成绩不用于反复选择模型。
3. MAE 为全部绝对误差之和除以目标值数；RMSE 为全部平方误差的均值再开方；不能平均各批次的 RMSE。
4. WAPE 为 `sum(abs(prediction-target)) / sum(abs(target))`，展示时明确比例或百分数。分母为零时报告未定义及样本量，不能静默加小数后当作正常指标。
5. Naive、Seasonal Naive、LSTM、TFT 优先在完整实验子集比较。ARIMA 若仅覆盖代表序列，单列对照表，并在同一代表序列上补算其他模型指标，不与完整子集指标直接排名。
6. 保存逐序列、逐预测日的结果，至少包含门店、商品、预测起点、标签日期、预测步长、真实值、预测值、模型与 run 标识。

深度模型不必胜出。若没有稳定提升，应检查数据与训练、说明适用范围，如实报告基线的竞争力。

## 多变量输入与信息边界

| 类型 | 候选字段 | 使用边界 |
| --- | --- | --- |
| 历史观测 | 销量、历史价格、lag、rolling | 只取预测起点及之前已知的值 |
| 未来已知 | 当前 is_weekend、month、year_offset、wday；后续可补已公开的节日或事件日历 | 未来销量派生值不属于这一类；恢复早期原始 year 版本须切回当次编码 |
| 静态属性 | 当前 store_id、item_id；category 为候选扩展 | 固定字段顺序与编号，后续补未知类别规则 |

先完成一个清楚、可测试的输入约定，再扩展特征。对未知未来价格，默认不使用；只有明确的已知价格计划实验才允许输入，不能仅因离线文件中存在未来价格便认为上线时可知。

原始价格 null 保留，模型历史输入副本中填 0；本轮按已确定的输入方案不新增 price_missing。当前价格空值均对应首次有效价格之前的零销量，支持上架前阶段的解释，数据未直接提供上架状态。需要数据统计量的缩放、填充值估计及销量分组阈值，仅在训练部分拟合。

静态 ID 按固定实体目录 unique 后排序编号，当前完整子集与训练期门店、商品集合一致；编号不使用未来销量统计。保持完整 sales 构建窗口，再按标签窗口 split，避免截断预测所需历史。映射及字段顺序应随模型归档，未知类别策略仍待完善。历史特征必须分序列计算；多步预测中不可读取标签区间真实销量计算未来 lag/rolling。

## 执行顺序

### 1. 建立统一评估与周期基线

已完成 MAE/RMSE/WAPE 的全局聚合与两种基线验证。Seasonal Naive 使用最后一周循环预测 30 天，不读取验证区间真实销量。逐目标预测导出仍待补充。

### 2. 完成 LSTM 训练闭环并接入 MLflow

已完成单变量 LSTM 训练、早停、最佳模型恢复和 MLflow 逐轮记录；保留 Naive 无优化器分支。完整配置、数据版本和恢复所需元数据仍需补齐，不能将当前可变 YAML 当作历史运行快照。

### 3. 扩展多变量输入并完成 TFT

已完成 12/15 特征 LSTM 和 TFT 真实训练与恢复。TFTDataset、GRN、VSN、静态上下文、编码/解码 LSTM、共享 V 的因果注意力与单值预测头均有测试；本轮统一使用 MAE，未实现多分位数损失。TFT 当前单层、单头、Dropout=0，MAE 略低但 RMSE 较高，应同时报告精度与训练成本。完整数值标准化未实现，单变量/12 特征 LSTM 为同架构特征组对照。

train.py 尚未显式透传 TFT 的 dropout、num_heads，当前默认值与 YAML 相同；后续调整参数前先同步入口，并归档实际生效参数。

### 4. 补 ARIMA 代表性对照与可选 HPO

代表序列选择规则在训练数据上确定并保存，不能根据最终效果挑选。ARIMA 与其他模型在同一代表集合比较。HPO 若实施，固定验证规则、搜索范围、trial 预算、随机种子与剪枝记录，测试集不进入调参目标。

### 5. 固定方案，做最终分析与展示

按验证结果固定配置与 checkpoint 后运行最终测试。误差切片至少包括：

- 品类：FOODS、HOBBIES、HOUSEHOLD。
- 销量水平：按训练期统计确定 high/medium/low 阈值，不能用测试期销量分组。
- 预测步长：Day 1–7、8–14、15–30。

各片报告样本量与统一指标，区分观察到的差异与能够支持的解释。当前仅有一个验证和一个测试起点，不能据此声称跨季节稳定或有统计显著性。event、门店、价格变化为可选附加切片；价格变化不直接等于真实促销。

## MLflow 最小记录

每个正式 run 至少记录：模型、代码版本、数据版本与文件校验标识、采样与日期边界、输入特征、超参数、随机种子、设备、训练耗时、逐轮指标、最佳 epoch、最终 MAE/RMSE/WAPE、checkpoint、预测结果及切片分析。数据文件继续由 MinIO/本地管理，run 记录位置与版本，不要求把全量 Parquet 重复上传为每次实验的 artifact。
